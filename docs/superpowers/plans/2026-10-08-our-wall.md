# Our Wall Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build "Our Wall" — a private two-person feed of links and notes with previews, reactions, comments, collections, pinning, spouse push, a home tile, and an Android Share-menu target.

**Architecture:** Existing `feed_items` / `feed_reactions` / `feed_comments` tables get per-operation RLS, a column guard, data checks and push triggers in one new migration. A new `lib/features/wall/` feature (data / domain / presentation) streams those tables via Supabase realtime, fetches link previews on-device, and renders story cards in Lovinity's existing design system. A small Kotlin MethodChannel bridge delivers Android `ACTION_SEND` text into the app, which opens the add sheet pre-filled.

**Tech Stack:** Flutter 3.44 / Dart ^3.12, Riverpod 3 (`flutter_riverpod`), go_router 17, supabase_flutter 2.16, Postgres (Supabase local via Docker), Deno (edge function tests via `npx --yes deno`), Kotlin (Android `MainActivity`). New packages: `http`, `html`, `cached_network_image`, `url_launcher`.

**Spec:** `docs/superpowers/specs/2026-10-08-our-wall-design.md` — read it before starting any task.

## Global Constraints

- Add packages with `flutter pub add <name>` (latest versions); never hand-pin versions.
- Never run `supabase db push` (it targets the production Cloud project). Verify migrations locally with `supabase db reset`.
- The local stack must be running for DB/integration tests: `supabase start` (Docker Desktop running).
- New migration file name: `supabase/migrations/20261008000001_our_wall.sql`.
- Collections (DB keys): `recipes`, `places`, `home`, `funny`, `deen` — labels Recipes, Places, Home, Funny, Deen.
- Sources (DB keys): `youtube`, `instagram`, `tiktok`, `article`, `note`.
- Reactions (DB keys → emoji): `heart` 🤍, `laugh` 😂, `fire` 🔥, `dua` 🤲, `wow` 😮, `star` ⭐ — in that order everywhere.
- Limits: url ≤ 2048 chars and must start `http://` or `https://`; title ≤ 300; description ≤ 1000; note ≤ 1000; comment body 1–1000.
- Link preview fetch: on-device only, http/https only, 5 s total timeout, read at most 512 KB of HTML.
- Never read the clipboard silently: only `Clipboard.hasStrings()` until the user taps "Paste copied link".
- Push: type `wall`; item title `"<display_name> shared something"` body `"New on your Wall 💛"`; comment title `"<display_name> replied"` body `"New comment on your Wall"`; fallback name `"Your partner"`; no item content in pushes; no push on reactions.
- UI uses existing tokens/widgets only (`LovColors` via `Theme.of(context).colorScheme`, `LovSpace`, `LovRadius`, `LovMotion`, `LovEnter`, `LovShimmerBox`, `LovCard`, `LovButton`). Must work in dark and light theme.
- Commit after each task with a `feat(wall): …` / `test(wall): …` / `docs(wall): …` message.

## Review Focus

1. **Very long content** (300-char title, 1000-char note, long display name) on a 320 px-wide phone → cards ellipsize, no RenderFlex overflow. Test: Task 7 "long content does not overflow at 320px".
2. **Messy real-world pages** — relative `og:image` (`/img/a.png`), HTML entities in titles, a PDF or other non-HTML response, an endless/huge response → absolute image URL, decoded title, `null` preview, and the 5 s / 512 KB caps hold. Tests: Task 4 "resolves relative og:image", "non-HTML returns null", "times out to null", "only reads the first maxBytes".
3. **Spouse deletes an item while I'm viewing it** → detail screen switches to "This item was removed", no crash. Test: Task 10 "shows removed state when the item disappears".
4. **Rapid double-tap on a reaction** → the second insert must not error on the `(item_id, user_id, reaction)` primary key; UI ends consistent. Tests: Task 5 "addReaction twice is idempotent", Task 10 optimistic toggle test.
5. **A second share arrives while the add sheet is already open** → no stacked sheets; the newer share opens after the current sheet closes. Test: Task 12 "a pending share opens the sheet pre-filled; a second one queues".

```sql
-- Our Wall (shared feed): per-operation RLS, an update guard, data checks
-- and spouse push triggers for feed_items / feed_comments / feed_reactions.
-- Spec: docs/superpowers/specs/2026-10-08-our-wall-design.md

------------------------------------------------------------------
-- 1. Normalise any existing rows so the new checks apply cleanly.
------------------------------------------------------------------
update public.feed_items set url = null
  where url is not null and (url !~* '^https?://' or length(url) > 2048);
update public.feed_items set note = null where note is not null and length(btrim(note)) = 0;
delete from public.feed_items where url is null and note is null;
update public.feed_items set source = null
  where source is not null and source not in ('youtube', 'instagram', 'tiktok', 'article', 'note');
update public.feed_items set collection = null
  where collection is not null and collection not in ('recipes', 'places', 'home', 'funny', 'deen');
update public.feed_items set note = left(note, 1000) where length(note) > 1000;
update public.feed_items set title = left(title, 300) where length(title) > 300;
update public.feed_items set description = left(description, 1000) where length(description) > 1000;
delete from public.feed_comments where length(btrim(body)) = 0;
update public.feed_comments set body = left(body, 1000) where length(body) > 1000;
delete from public.feed_reactions
  where reaction not in ('heart', 'laugh', 'fire', 'dua', 'wow', 'star');

------------------------------------------------------------------
-- 2. Data checks.
------------------------------------------------------------------
alter table public.feed_items
  add constraint feed_items_url_check
    check (url is null or (url ~* '^https?://' and length(url) <= 2048)),
  add constraint feed_items_source_check
    check (source is null or source in ('youtube', 'instagram', 'tiktok', 'article', 'note')),
  add constraint feed_items_collection_check
    check (collection is null or collection in ('recipes', 'places', 'home', 'funny', 'deen')),
  add constraint feed_items_note_len check (note is null or length(note) <= 1000),
  add constraint feed_items_title_len check (title is null or length(title) <= 300),
  add constraint feed_items_description_len
    check (description is null or length(description) <= 1000),
  add constraint feed_items_has_content
    check (url is not null or (note is not null and length(btrim(note)) > 0));

alter table public.feed_comments
  add constraint feed_comments_body_len
    check (length(btrim(body)) between 1 and 1000);

alter table public.feed_reactions
  add constraint feed_reactions_reaction_check
    check (reaction in ('heart', 'laugh', 'fire', 'dua', 'wow', 'star'));

------------------------------------------------------------------
-- 3. Per-operation RLS (replaces the blanket `for all` couple policy).
------------------------------------------------------------------
drop policy if exists feed_items_couple_rls on public.feed_items;
drop policy if exists feed_comments_couple_rls on public.feed_comments;
drop policy if exists feed_reactions_couple_rls on public.feed_reactions;

create policy feed_items_select on public.feed_items
  for select using (public.is_couple_member(couple_id));
create policy feed_items_insert on public.feed_items
  for insert with check (public.is_couple_member(couple_id) and added_by = auth.uid());
-- Either spouse may pin or file an item; feed_items_guard limits WHAT changes.
create policy feed_items_update on public.feed_items
  for update using (public.is_couple_member(couple_id))
  with check (public.is_couple_member(couple_id));
create policy feed_items_delete on public.feed_items
  for delete using (public.is_couple_member(couple_id) and added_by = auth.uid());

create policy feed_comments_select on public.feed_comments
  for select using (public.is_couple_member(couple_id));
create policy feed_comments_insert on public.feed_comments
  for insert with check (
    public.is_couple_member(couple_id)
    and author_id = auth.uid()
    and exists (select 1 from public.feed_items i
                where i.id = item_id and i.couple_id = feed_comments.couple_id)
  );
create policy feed_comments_delete on public.feed_comments
  for delete using (public.is_couple_member(couple_id) and author_id = auth.uid());

create policy feed_reactions_select on public.feed_reactions
  for select using (public.is_couple_member(couple_id));
create policy feed_reactions_insert on public.feed_reactions
  for insert with check (
    public.is_couple_member(couple_id)
    and user_id = auth.uid()
    and exists (select 1 from public.feed_items i
                where i.id = item_id and i.couple_id = feed_reactions.couple_id)
  );
create policy feed_reactions_delete on public.feed_reactions
  for delete using (public.is_couple_member(couple_id) and user_id = auth.uid());

------------------------------------------------------------------
-- 4. Update guard: only is_pinned and collection may change after posting.
--    RLS cannot compare OLD vs NEW, so this lives in a trigger.
------------------------------------------------------------------
create or replace function public.feed_items_guard_update()
returns trigger
language plpgsql
set search_path = public
as $$
begin
  if (new.id, new.couple_id, new.added_by, new.url, new.title, new.description,
      new.image_url, new.source, new.media_url, new.media_mime, new.note,
      new.created_at)
     is distinct from
     (old.id, old.couple_id, old.added_by, old.url, old.title, old.description,
      old.image_url, old.source, old.media_url, old.media_mime, old.note,
      old.created_at) then
    raise exception 'feed_items: only is_pinned and collection can change after posting'
      using errcode = '42501';
  end if;
  return new;
end;
$$;

drop trigger if exists feed_items_guard on public.feed_items;
create trigger feed_items_guard
  before update on public.feed_items
  for each row execute function public.feed_items_guard_update();

------------------------------------------------------------------
-- 5. Spouse push on new items and comments (never on reactions).
--    dispatch_push is best-effort and never raises.
------------------------------------------------------------------
create or replace function public.notify_wall_item()
returns trigger
language plpgsql security definer
set search_path = public
as $$
declare
  v_spouse uuid;
  v_name   text;
begin
  select case when member_a = new.added_by then member_b else member_a end
    into v_spouse
    from public.couples where id = new.couple_id;
  if v_spouse is null then
    return new;
  end if;
  select nullif(btrim(display_name), '') into v_name
    from public.users where id = new.added_by;
```

```dart
import 'package:intl/intl.dart';

import 'wall_models.dart';

/// Compact relative time for Wall cards: now, 5m, 3h, 2d, then "1 Sep".
String formatWallTime(DateTime t, {DateTime? now}) {
  final n = now ?? DateTime.now();
  final d = n.difference(t);
  if (d.inMinutes < 1) return 'now';
  if (d.inHours < 1) return '${d.inMinutes}m';
  if (d.inDays < 1) return '${d.inHours}h';
  if (d.inDays < 7) return '${d.inDays}d';
  return DateFormat('d MMM').format(t);
}

/// Per-kind counts for one item, in [WallReactionKind] order, zero counts

}) {
  final counts = <WallReactionKind, int>{};
  final mine = <WallReactionKind>{};
  for (final r in reactions) {
    if (r.itemId != itemId) continue;
    counts[r.kind] = (counts[r.kind] ?? 0) + 1;
    if (r.userId == selfId) mine.add(r.kind);
  }
  return [
    for (final k in WallReactionKind.values)
      if ((counts[k] ?? 0) > 0)
        ReactionCount(kind: k, count: counts[k]!, mine: mine.contains(k)),
  ];
}

/// Overlays not-yet-confirmed toggles ([pending]: kind -> wanted "mine"
/// state) on the server summary, so a tap shows instantly.
List<ReactionCount> applyPendingReactions(
  List<ReactionCount> server,
  Map<WallReactionKind, bool> pending,
) {
  if (pending.isEmpty) return server;
  final byKind = {for (final r in server) r.kind: r};
  final out = <ReactionCount>[];
  for (final kind in WallReactionKind.values) {
    final s = byKind[kind];
    var count = s?.count ?? 0;
    var mine = s?.mine ?? false;
    final want = pending[kind];
    if (want != null && want != mine) {
      count += want ? 1 : -1;
      mine = want;
    }
    if (count > 0) out.add(ReactionCount(kind: kind, count: count, mine: mine));
  }
  return out;
}

    for (final i in items)
      if (i.addedBy != selfId &&
          (lastVisit == null || i.createdAt.isAfter(lastVisit)))
        i.id,
  };
}

int itemsThisWeek(Iterable<WallItem> items, {required DateTime now}) {
  final from = now.subtract(const Duration(days: 7));
  return items.where((i) => i.createdAt.isAfter(from)).length;
```

```dart
import 'wall_models.dart';

final _urlRe = RegExp(r'''https?://[^\s<>"']+''', caseSensitive: false);
const _trailing = '.,!?;:"\')]}>…';

/// The first http(s) URL in [text], with trailing punctuation trimmed.
/// A closing paren is kept when the URL also contains a matching "(".
String? extractFirstUrl(String text) {
  final match = _urlRe.firstMatch(text);
  if (match == null) return null;
  var url = match.group(0)!;
  while (url.isNotEmpty && _trailing.contains(url[url.length - 1])) {
    if (url.endsWith(')') &&
        '('.allMatches(url).length >= ')'.allMatches(url).length) {
      break;
    }
    url = url.substring(0, url.length - 1);
  }
  final uri = Uri.tryParse(url);
  if (uri == null || uri.host.isEmpty) return null;
  return url;
}

/// Source for a URL, from its host (subdomains included).
WallSource classifyUrl(String url) {
  final host = Uri.tryParse(url)?.host.toLowerCase() ?? '';
  bool on(String domain) => host == domain || host.endsWith('.$domain');
  if (on('youtube.com') || on('youtu.be')) return WallSource.youtube;
  if (on('instagram.com')) return WallSource.instagram;
  if (on('tiktok.com')) return WallSource.tiktok;
  return WallSource.article;
}

/// Splits text shared into the app: a link if there is one (the rest is
/// dropped — apps prepend titles/marketing copy), otherwise a note capped at
/// 1000 characters.
({String? url, String? note}) parseSharedText(String text) {
  final url = extractFirstUrl(text);
  if (url != null) return (url: url, note: null);
  final note = text.trim();
  if (note.isEmpty) return (url: null, note: null);
  return (url: null, note: note.length > 1000 ? note.substring(0, 1000) : note);
}
```

```dart
import 'dart:convert';
import 'dart:typed_data';

import 'package:flutter/foundation.dart';

import 'package:http/http.dart' as http;

import '../domain/wall_models.dart';

@immutable
class LinkPreview {
  const LinkPreview({this.title, this.description, this.imageUrl, this.siteName});

  final String? title;
  final String? description;
  final String? imageUrl;
  final String? siteName;
}

/// Fetches link previews ON THE DEVICE (never via our server), so there is
/// no server-side "fetch any URL" surface. Never throws: any failure,
/// non-HTML response or timeout yields null and the item posts without one.
class LinkPreviewService {
  LinkPreviewService({http.Client? client, this.timeout = const Duration(seconds: 5)})
      : _client = client ?? http.Client();

  static const maxBytes = 512 * 1024;
  static const _userAgent = 'Mozilla/5.0 (compatible; LovinityLinkPreview/1.0)';

  final http.Client _client;
  final Duration timeout;

  Future<LinkPreview?> fetch(String url) async {
    final uri = Uri.tryParse(url);
    if (uri == null || !(uri.scheme == 'http' || uri.scheme == 'https')) {
      return null;
    }
    try {
      return await _fetch(url, uri).timeout(timeout, onTimeout: () => null);
    } catch (_) {
      return null;
    }
  }

  Future<LinkPreview?> _fetch(String url, Uri uri) async {
    final oembed = oembedEndpoint(url, classifyUrl(url));
    if (oembed != null) {
      try {
        final res = await _client.get(oembed, headers: {'User-Agent': _userAgent});
        if (res.statusCode == 200) {
          final p = parseOEmbed(utf8.decode(res.bodyBytes, allowMalformed: true));
          if (p != null) return p;
        }
      } catch (_) {
        // fall through to the page itself
      }
    }

    final req = http.Request('GET', uri)
      ..headers['User-Agent'] = _userAgent
      ..headers['Accept'] = 'text/html,application/xhtml+xml';
    final res = await _client.send(req);
    if (res.statusCode != 200) return null;
    final type = res.headers['content-type'] ?? '';
    if (!type.contains('html')) return null;

    final bytes = BytesBuilder(copy: false);
    await for (final chunk in res.stream) {
      bytes.add(chunk);
      if (bytes.length >= maxBytes) break; // cancels the rest of the body
    }
    final html = utf8.decode(bytes.takeBytes(), allowMalformed: true);
    return parseHtmlPreview(html, baseUrl: res.request?.url ?? uri);
  }

  void close() => _client.close();
}

/// Public oEmbed endpoints that work without an API key.
Uri? oembedEndpoint(String url, WallSource source) => switch (source) {
      WallSource.youtube =>
        Uri.https('www.youtube.com', '/oembed', {'url': url, 'format': 'json'}),
      WallSource.tiktok => Uri.https('www.tiktok.com', '/oembed', {'url': url}),
      _ => null,
    };

LinkPreview? parseOEmbed(String body) {
  try {
    final json = jsonDecode(body);
    if (json is! Map) return null;
    final title = _clean(json['title'] as String?, 300);
    final image = _httpUrl(json['thumbnail_url'] as String?, null);
    if (title == null && image == null) return null;
    return LinkPreview(
      title: title,
      imageUrl: image,
      siteName: _clean(json['provider_name'] as String?, 100),
    );
  } catch (_) {
    return null;
  }
}

LinkPreview? parseHtmlPreview(String html, {required Uri baseUrl}) {
  final doc = html_parser.parse(html);
  String? meta(String key) {
    for (final m in doc.querySelectorAll('meta')) {
      final k = m.attributes['property'] ?? m.attributes['name'];
      if (k != null && k.toLowerCase() == key) {
        final v = m.attributes['content']?.trim();
        if (v != null && v.isNotEmpty) return v;
      }
    }
    return null;
  }

  final title = _clean(
      meta('og:title') ?? meta('twitter:title') ?? doc.querySelector('title')?.text,
      300);
  final description = _clean(
      meta('og:description') ?? meta('twitter:description') ?? meta('description'),
      1000);
  final image = _httpUrl(
      meta('og:image') ?? meta('og:image:url') ?? meta('twitter:image'), baseUrl);
  final site = _clean(meta('og:site_name'), 100);

  if (title == null && image == null && description == null) return null;
  return LinkPreview(
      title: title, description: description, imageUrl: image, siteName: site);
}

String? _clean(String? s, int max) {
  if (s == null) return null;
  final t = s.replaceAll(RegExp(r'\s+'), ' ').trim();
  if (t.isEmpty) return null;
  return t.length > max ? t.substring(0, max) : t;
}

String? _httpUrl(String? raw, Uri? base) {
  if (raw == null || raw.trim().isEmpty) return null;
  final resolved = base == null ? Uri.tryParse(raw.trim()) : base.resolve(raw.trim());
  if (resolved == null) return null;
  if (resolved.scheme != 'http' && resolved.scheme != 'https') return null;
  final s = resolved.toString();
  return s.length > 2048 ? null : s;
}
```

```dart
import 'package:supabase_flutter/supabase_flutter.dart';

import '../domain/wall_models.dart';

/// Supabase access for Our Wall. Rows are protected by RLS (couple members
/// only; authors alone may delete). Streams are realtime and re-emit the
/// full list on every change.
class WallRepository {
  WallRepository(this._client);

  final SupabaseClient _client;

  Stream<List<WallItem>> watchItems(String coupleId) {
    return _client
        .from('feed_items')
        .stream(primaryKey: ['id'])
        .eq('couple_id', coupleId)
        .map((rows) => [
              for (final r in rows) WallItem.fromRow(Map<String, dynamic>.from(r)),
            ]..sort((a, b) => b.createdAt.compareTo(a.createdAt)));
  }

  Stream<List<WallReaction>> watchReactions(String coupleId) {
    return _client
        .from('feed_reactions')
        .stream(primaryKey: ['item_id', 'user_id', 'reaction'])
        .eq('couple_id', coupleId)
        .map((rows) => [
              for (final r in rows)
                ?WallReaction.tryFromRow(Map<String, dynamic>.from(r)),
            ]);
  }

  Stream<List<WallComment>> watchComments(String coupleId) {
    return _client
        .from('feed_comments')
        .stream(primaryKey: ['id'])
        .eq('couple_id', coupleId)
        .map((rows) => [
              for (final r in rows) WallComment.fromRow(Map<String, dynamic>.from(r)),
            ]..sort((a, b) => a.createdAt.compareTo(b.createdAt)));
  }

  Future<WallItem> addItem({
    required String coupleId,
    required String userId,
    String? url,
    String? title,
    String? description,
    String? imageUrl,
    required WallSource source,
    WallCollection? collection,
    String? note,
  }) async {
    final row = await _client
        .from('feed_items')
        .insert({
          'couple_id': coupleId,
          'added_by': userId,
          'url': url,
          'title': title,
          'description': description,
          'image_url': imageUrl,
          'source': source.key,
          'collection': collection?.key,
          'note': note,
        })
        .select()
        .single();
    return WallItem.fromRow(row);
  }

  Future<void> deleteItem(String itemId) =>
      _client.from('feed_items').delete().eq('id', itemId);

  Future<void> setPinned(String itemId, bool pinned) =>
      _client.from('feed_items').update({'is_pinned': pinned}).eq('id', itemId);

  Future<void> setCollection(String itemId, WallCollection? collection) => _client
      .from('feed_items')
      .update({'collection': collection?.key}).eq('id', itemId);

  /// Idempotent: a double tap must not fail on the primary key.
  Future<void> addReaction({
    required String coupleId,
    required String itemId,
    required String userId,
    required WallReactionKind kind,
  }) =>
      _client.from('feed_reactions').upsert(
        {
          'item_id': itemId,
          'user_id': userId,
          'reaction': kind.key,
          'couple_id': coupleId,
        },
        onConflict: 'item_id,user_id,reaction',
        ignoreDuplicates: true,
      );

  Future<void> removeReaction({
    required String itemId,
    required String userId,
    required WallReactionKind kind,
  }) =>
      _client
          .from('feed_reactions')
          .delete()
          .eq('item_id', itemId)
          .eq('user_id', userId)
          .eq('reaction', kind.key);

  Future<void> addComment({
    required String coupleId,
    required String itemId,
    required String userId,
    required String body,
  }) =>
      _client.from('feed_comments').insert({
        'item_id': itemId,
        'couple_id': coupleId,
        'author_id': userId,
        'body': body,
      });

  Future<void> deleteComment(String commentId) =>
      _client.from('feed_comments').delete().eq('id', commentId);
}
```

Note: `?WallReaction.tryFromRow(...)` is Dart 3.8+ null-aware collection element syntax (the project's SDK is ^3.12). If the analyzer rejects it, replace with `if (WallReaction.tryFromRow(Map<String, dynamic>.from(r)) case final reaction?) reaction`.

```dart
Stream<T> _forCouple<T>(Ref ref, T empty, Stream<T> Function(String coupleId) open) {

  final couple = coupleAsync.asData?.value;

/// When this account last left the Wall. Stored on-device per account
/// (`wall.last_visit.<userId>`), so accounts sharing a device don't mix.
class WallLastVisit extends AsyncNotifier<DateTime?> {
  static String _key(String userId) => 'wall.last_visit.$userId';

  @override
  Future<DateTime?> build() async {
    final userId = ref.watch(wallSelfIdProvider);
    if (userId == null) return null;
    final raw = await ref.read(secureStoreProvider).read(_key(userId));
    return raw == null ? null : DateTime.tryParse(raw);
  }

  Future<void> markNow() async {
    final userId = ref.read(wallSelfIdProvider);
    if (userId == null) return;
    final now = DateTime.now();
    state = AsyncData(now);
    try {
      await ref.read(secureStoreProvider).write(_key(userId), now.toIso8601String());
    } catch (_) {
      // Best-effort: worst case the dots reappear next launch.
    }
  }
}

    AsyncNotifierProvider<WallLastVisit, DateTime?>(WallLastVisit.new);

    selfId: ref.watch(wallSelfIdProvider),
    lastVisit: lastVisit.asData?.value,
  );
```

```dart
class _AddToWallSheetState extends ConsumerState<AddToWallSheet> {
  late final TextEditingController _url =
      TextEditingController(text: widget.initialUrl ?? '');
  late final TextEditingController _note =
      TextEditingController(text: widget.initialNote ?? '');

  WallCollection? _collection;
  bool _clipboardHasText = false;
  Timer? _debounce;

  int _previewToken = 0;
  String? _previewFor;
  Future<LinkPreview?>? _previewFuture;
  LinkPreview? _preview;
  bool _loadingPreview = false;

  bool _submitting = false;
  String? _error;

  @override
  void initState() {
    super.initState();
    _url.addListener(_onUrlChanged);
    _note.addListener(() => setState(() {}));
    // setState isn't allowed during initState, so a pre-filled link (from the
    // Share menu) starts loading its preview right after the first frame.
    if (_validUrl != null) {
      WidgetsBinding.instance.addPostFrameCallback((_) => _loadPreview());
    }
    _checkClipboard();
  }

  @override
  void dispose() {
    _debounce?.cancel();
    _url.dispose();
    _note.dispose();
    super.dispose();
  }

  String? get _validUrl => extractFirstUrl(_url.text);
  bool get _urlTextInvalid => _url.text.trim().isNotEmpty && _validUrl == null;
  bool get _canSubmit =>
      !_submitting &&
      !_urlTextInvalid &&
      (_validUrl != null || _note.text.trim().isNotEmpty);

  /// Only asks WHETHER there is text — never reads it until the user taps,
  /// so no "pasted from…" banner/toast.
  Future<void> _checkClipboard() async {
    if (_url.text.isNotEmpty) return;
    try {
      final has = await Clipboard.hasStrings();
      if (mounted) setState(() => _clipboardHasText = has);
    } catch (_) {}
  }

  Future<void> _pasteFromClipboard() async {
    final data = await Clipboard.getData(Clipboard.kTextPlain);
    final text = data?.text;
    if (!mounted || text == null) return;
    final parsed = parseSharedText(text);
    setState(() => _clipboardHasText = false);
    // Set the controllers outside setState: their listeners call setState.
    if (parsed.url != null) {
      _url.text = parsed.url!;
    } else if (_note.text.isEmpty && parsed.note != null) {
      _note.text = parsed.note!;
    }
  }

  void _onUrlChanged() {
    setState(() => _error = null);
    _debounce?.cancel();
    _debounce = Timer(const Duration(milliseconds: 400), _loadPreview);
  }

  void _loadPreview() {
    if (!mounted) return;
    final url = _validUrl;
    if (url == null) {
      if (_previewFor != null) {
        setState(() {
          _previewFor = null;
          _previewFuture = null;
          _preview = null;
          _loadingPreview = false;
        });
      }
      return;
    }
    if (url == _previewFor) return;
    final token = ++_previewToken;
    final future = ref.read(linkPreviewServiceProvider).fetch(url);
    setState(() {
      _previewFor = url;
      _previewFuture = future;
      _preview = null;
      _loadingPreview = true;
    });
    future.then((p) {
      if (!mounted || token != _previewToken) return;
      setState(() {
        _preview = p;
        _loadingPreview = false;
      });
    });
  }

  Future<void> _submit() async {
    final couple = ref.read(currentCoupleProvider).asData?.value;
    final selfId = ref.read(wallSelfIdProvider);
    if (couple == null || selfId == null) return;
    final url = _validUrl;
    final note = _note.text.trim();
    setState(() {
      _submitting = true;
      _error = null;
    });
    try {
      LinkPreview? preview;
      if (url != null) {
        if (url != _previewFor) _loadPreview();
        preview = await (_previewFuture ?? Future<LinkPreview?>.value(null));
      }
      await ref.read(wallRepositoryProvider).addItem(
            coupleId: couple.id,
            userId: selfId,
            url: url,
            title: url == null ? null : (preview?.title ?? domainOf(url)),

            source: url == null ? WallSource.note : classifyUrl(url),
            collection: _collection,
            note: note.isEmpty ? null : note,

    } catch (_) {
```

```dart
  ConsumerState<WallItemScreen> createState() => _WallItemScreenState();

class _WallItemScreenState extends ConsumerState<WallItemScreen> {
  /// Reaction toggles not yet reflected by the server: kind -> wanted "mine".
  final _pending = <WallReactionKind, bool>{};
  final _comment = TextEditingController();
  bool _sending = false;

  @override
  void initState() {
    super.initState();
    _comment.addListener(() => setState(() {}));
  }

  @override
  void dispose() {
    _comment.dispose();
    super.dispose();
  }

  void _snack(String message) => ScaffoldMessenger.maybeOf(context)
      ?.showSnackBar(SnackBar(content: Text(message)));

  /// Drops pending toggles the server now agrees with.
  void _prunePending() {
    if (_pending.isEmpty || !mounted) return;
    final server = ref.read(wallReactionSummaryProvider(widget.itemId));
    bool serverMine(WallReactionKind k) {
      for (final r in server) {
        if (r.kind == k) return r.mine;
      }
      return false;
    }

    setState(() => _pending.removeWhere((k, want) => serverMine(k) == want));
  }

  Future<void> _toggleReaction(
      WallItem item, WallReactionKind kind, List<ReactionCount> shown) async {
    final selfId = ref.read(wallSelfIdProvider);
    if (selfId == null) return;
    final currentlyMine = shown.any((r) => r.kind == kind && r.mine);
    final want = !currentlyMine;
    setState(() => _pending[kind] = want);
    final repo = ref.read(wallRepositoryProvider);
    try {
      if (want) {
        await repo.addReaction(
            coupleId: item.coupleId, itemId: item.id, userId: selfId, kind: kind);
      } else {
        await repo.removeReaction(itemId: item.id, userId: selfId, kind: kind);
      }
    } catch (_) {
      if (!mounted) return;
      setState(() => _pending.remove(kind));
      _snack("Couldn't save your reaction");
    }
  }

  Future<void> _sendComment(WallItem item) async {
    final body = _comment.text.trim();
    final selfId = ref.read(wallSelfIdProvider);
    if (body.isEmpty || selfId == null || _sending) return;
    setState(() => _sending = true);
    try {
      await ref.read(wallRepositoryProvider).addComment(
          coupleId: item.coupleId, itemId: item.id, userId: selfId, body: body);
      _comment.clear();
      HapticFeedback.lightImpact();
    } catch (_) {
      _snack("Couldn't send your comment");
    } finally {
      if (mounted) setState(() => _sending = false);
    }
  }

  Future<bool> _confirm(String title, String body) async {
    final ok = await showDialog<bool>(
      context: context,
      builder: (ctx) => AlertDialog(
        title: Text(title),
        content: Text(body),
        actions: [
          TextButton(onPressed: () => Navigator.pop(ctx, false), child: const Text('Cancel')),
          TextButton(onPressed: () => Navigator.pop(ctx, true), child: const Text('Delete')),
        ],
      ),
    );
    return ok ?? false;
  }

  Future<void> _deleteItem(WallItem item) async {
    if (!await _confirm('Delete from our Wall?', 'This removes it for both of you.')) return;
    try {
      await ref.read(wallRepositoryProvider).deleteItem(item.id);
      if (mounted) await Navigator.of(context).maybePop();
    } catch (_) {
      _snack("Couldn't delete it");
    }
  }

  Future<void> _deleteComment(WallComment c) async {
    if (!await _confirm('Delete comment?', 'This removes it for both of you.')) return;
    try {
      await ref.read(wallRepositoryProvider).deleteComment(c.id);
    } catch (_) {
      _snack("Couldn't delete the comment");
    }
  }

  Future<void> _changeCollection(WallItem item) async {
    final picked = await showModalBottomSheet<({WallCollection? value})>(
      context: context,
      showDragHandle: true,
      builder: (ctx) => Padding(
        padding: const EdgeInsets.fromLTRB(LovSpace.lg, 0, LovSpace.lg, LovSpace.xl),
        child: Wrap(
          spacing: LovSpace.sm,
          runSpacing: LovSpace.sm,
          children: [
            WallPill(
              label: 'None',
              selected: item.collection == null,
              onTap: () => Navigator.pop(ctx, (value: null)),
            ),
            for (final c in WallCollection.values)
              WallPill(
                label: c.label,
                selected: item.collection == c,
                onTap: () => Navigator.pop(ctx, (value: c)),
              ),
          ],
        ),
      ),
    );
    if (picked == null) return;
    try {
      await ref.read(wallRepositoryProvider).setCollection(item.id, picked.value);
    } catch (_) {
      _snack("Couldn't change the collection");
    }
  }

  Future<void> _togglePin(WallItem item) async {
    try {
      await ref.read(wallRepositoryProvider).setPinned(item.id, !item.isPinned);
      HapticFeedback.selectionClick();
    } catch (_) {
      _snack("Couldn't update the pin");
    }
  }

  @override
  Widget build(BuildContext context) {
    ref.listen(wallReactionsProvider, (_, _) => _prunePending());
    final itemAsync = ref.watch(wallItemProvider(widget.itemId));
    return itemAsync.when(
      loading: () => Scaffold(
        appBar: AppBar(),
        body: const Center(child: CircularProgressIndicator.adaptive()),
      ),
      error: (_, _) => const _Gone(message: "Couldn't load this item"),
      data: (item) =>
          item == null ? const _Gone(message: 'This item was removed') : _buildItem(item),
    );
  }

  Widget _buildItem(WallItem item) {
    final theme = Theme.of(context);
    final scheme = theme.colorScheme;
    final selfId = ref.watch(wallSelfIdProvider);
    final nameFor = ref.watch(wallNameForProvider);
    final isMine = item.addedBy == selfId;
    final summary = applyPendingReactions(
        ref.watch(wallReactionSummaryProvider(item.id)), _pending);
    final comments = ref.watch(wallItemCommentsProvider(item.id));
    final note = item.note?.trim();
    final meta = [
      if (item.domain != null) item.domain!,
```

```dart
import 'dart:async';

import 'package:flutter/foundation.dart';
import 'package:flutter/services.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';

/// Text another app shared into Lovinity via the OS Share menu.
@immutable
class SharedPayload {
  const SharedPayload({required this.text, this.subject});

  final String text;
  final String? subject;

  static SharedPayload? fromChannel(Object? raw) {
    if (raw is! Map) return null;
    final text = raw['text'];
    if (text is! String || text.trim().isEmpty) return null;
    final subject = raw['subject'];
    return SharedPayload(
      text: text,
      subject: subject is String && subject.trim().isNotEmpty ? subject : null,
    );
  }
}

/// Bridge to MainActivity.kt (Android only). Cold-start shares are pulled
/// with [takeInitialShare]; shares while running arrive on [shares].
class ShareIntake {
  ShareIntake({MethodChannel? channel, bool? enabled})
      : _channel = channel ?? const MethodChannel(channelName),
        _enabled = enabled ?? (!kIsWeb && defaultTargetPlatform == TargetPlatform.android) {
    if (_enabled) _channel.setMethodCallHandler(_handle);
  }

  static const channelName = 'lovinity/share';

  final MethodChannel _channel;
  final bool _enabled;
  final _controller = StreamController<SharedPayload>.broadcast();

  Stream<SharedPayload> get shares => _controller.stream;

  Future<SharedPayload?> takeInitialShare() async {
    if (!_enabled) return null;
    try {
      return SharedPayload.fromChannel(
          await _channel.invokeMethod<Object?>('getInitialShare'));
    } on MissingPluginException {
      return null;
    } on PlatformException {
      return null;
    }
  }

  Future<Object?> _handle(MethodCall call) async {
    if (call.method == 'onShare') {
      final payload = SharedPayload.fromChannel(call.arguments);
      if (payload != null && !_controller.isClosed) _controller.add(payload);
    }
    return null;
  }

  void dispose() {
    if (_enabled) _channel.setMethodCallHandler(null);
    _controller.close();
  }
}

final shareIntakeProvider = Provider<ShareIntake>((ref) {
  final intake = ShareIntake();
  ref.onDispose(intake.dispose);
  return intake;
});

/// A share waiting for the Wall screen to open its add sheet.
class PendingShare extends Notifier<SharedPayload?> {
  @override
  SharedPayload? build() => null;

  void set(SharedPayload payload) => state = payload;
  void clear() => state = null;
}

final pendingShareProvider =
```

```dart
/// Accepts a share only when signed in AND paired, storing it for the Wall
/// screen. Signed-out/unpaired shares are dropped (not held across sign-in).
/// Waits for the auth session first: on cold start the couple provider
/// briefly reports null before the restored session arrives.
final acceptShareProvider = Provider<Future<bool> Function(SharedPayload)>((ref) {
  return (payload) async {
    final session = await ref
        .read(authSessionProvider.future)
        .timeout(const Duration(seconds: 10));
    if (session == null) return false;
    final couple = await ref
        .read(currentCoupleProvider.future)
        .timeout(const Duration(seconds: 10));
    if (couple == null) return false;
    ref.read(pendingShareProvider.notifier).set(payload);
    return true;
  };
});
```

```kotlin
package com.lovinity.lovinity

import android.content.Intent
import io.flutter.embedding.android.FlutterActivity
import io.flutter.embedding.engine.FlutterEngine
import io.flutter.plugin.common.MethodChannel

/**
 * Delivers text shared from other apps (ACTION_SEND, text/plain) to Dart over
 * the "lovinity/share" channel. A cold-start share is held until Dart pulls it
 * with getInitialShare; later shares are pushed with onShare.
 */
class MainActivity : FlutterActivity() {
    private var channel: MethodChannel? = null
    private var initialShare: Map<String, String?>? = null

    override fun configureFlutterEngine(flutterEngine: FlutterEngine) {
        super.configureFlutterEngine(flutterEngine)
        initialShare = sharePayload(intent)
        // Consume it so a process restore doesn't redeliver the same share.
        if (initialShare != null) intent.action = Intent.ACTION_MAIN
        channel = MethodChannel(flutterEngine.dartExecutor.binaryMessenger, "lovinity/share").also {
            it.setMethodCallHandler { call, result ->
                when (call.method) {
                    "getInitialShare" -> {
                        result.success(initialShare)
                        initialShare = null
                    }
                    else -> result.notImplemented()
                }
            }
        }
    }

    override fun onNewIntent(intent: Intent) {
        super.onNewIntent(intent)
        setIntent(intent)
        val payload = sharePayload(intent) ?: return
        intent.action = Intent.ACTION_MAIN
        channel?.invokeMethod("onShare", payload)
    }

    private fun sharePayload(intent: Intent?): Map<String, String?>? {
        if (intent?.action != Intent.ACTION_SEND) return null
        if (intent.type?.startsWith("text/") != true) return null
        val text = intent.getStringExtra(Intent.EXTRA_TEXT) ?: return null
        return mapOf("text" to text, "subject" to intent.getStringExtra(Intent.EXTRA_SUBJECT))
    }
}
```
